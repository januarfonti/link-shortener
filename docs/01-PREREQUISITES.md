# 01 - Prerequisites

Before you begin, make sure you have the following ready.

---

## 1. Node.js

This link shortener requires Node.js version 18 or later.

### Check your Node.js version

```bash
node --version
```

If not installed or below version 18, download it at: https://nodejs.org/

> **Tip:** Choose the LTS (Long Term Support) version for stability.

---

## 2. Cloudflare Account

You need a Cloudflare account (free). If you don't have one:

1. Go to https://dash.cloudflare.com/sign-up
2. Register with your email
3. Verify your email

---

## 3. Terminal / Command Prompt

You'll run several commands via terminal:

- **macOS:** Terminal or iTerm2
- **Windows:** Command Prompt, PowerShell, or Windows Terminal
- **Linux:** Built-in terminal

---

## 4. Code Editor (Optional)

To edit configuration files, a code editor is recommended:

- [VS Code](https://code.visualstudio.com/) (Recommended)
- [Cursor](https://cursor.com/)
- Or any editor you prefer

---

## 5. Domain (Optional)

If you want to use your own domain like `go.yourdomain.com`:

- You can buy domains from Cloudflare, Namecheap, Google Domains, etc.
- Prices start at ~$10-15/year for a `.com` domain

> **Note:** If you don't have a domain, you can still deploy with a free Cloudflare subdomain: `your-project.pages.dev`

---

## Checklist

- [ ] Node.js v18+ installed
- [ ] Have a Cloudflare account
- [ ] Terminal ready to use
- [ ] (Optional) Code editor installed
- [ ] (Optional) Domain available
